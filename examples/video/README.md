# Video example

Puts the same cube as [the basic example](../basic/README.md) on a looping
animation shown on another screen, and recovers where the animation is in its
playback. The animation never holds still: the whole picture churns, swirls,
floods with other patterns and changes colour all the time, so nothing on
screen looks the same a second later. fastar tracks the screen from that
moving content alone, knowing where the content is at each moment of the clip.

The clip is generated by [`src/sim/showcase.ts`](../../src/sim/showcase.ts) and
loops seamlessly every 12 s: a mosaic of cells and a heap of ink shapes are
pulled through a field of counter-rotating swirls that surge and reverse while
the textures travel underneath, flood over each other along moving fronts,
and keep turning through every hue.

[`overlay.js`](overlay.js) keeps the cube in step with the clip: it turns with
the swirl at the centre of the screen, grows and shrinks as that swirl spreads
and gathers, and shifts hue as the clip's colours turn. It takes the swirl from
`scene.json` and the video time fastar reports for each camera frame, so the
cube only moves with the picture while that time is right.

```sh
npm run build                      # builds dist/fastar.js
npx tsx scripts/example-video.ts   # (re)generates clip.mp4, scene.json and targets.bin here (needs ffmpeg)
npx serve .                        # serve the repository root
```

Open `http://localhost:3000/examples/video/screen.html` on a computer and click
it to play the clip full screen. Then open
`http://localhost:3000/examples/video/` on a phone (over HTTPS, see
[the basic example](../basic/README.md)) and point it at the screen.

The site's version of this demo works from the same server too, at
`http://localhost:3000/site/demo/video.html` (it uses `dist/` and this
directory's files until `npm run build` puts copies next to it in `dist/site`).

`targets.bin` assumes the clip is shown 30 cm wide. Poses scale with that
width, so for another screen size recompile with its width in metres:

```sh
npx tsx cli/compile.ts --points 120 -o examples/video/targets.bin examples/video/clip.mp4:0.6
```

The same works for your own clips (ffmpeg must be installed), or compile them
in the browser on the [target compiler page](../../site/compile.html).
